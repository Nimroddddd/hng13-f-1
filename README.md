# HNG Frontend Stage 1 Project

A responsive multi-page website featuring a profile card, contact form, and about page built with semantic HTML, CSS, and vanilla JavaScript.

## Pages

### 1. Profile Card (index.html)
- Personal profile with avatar, bio, and social links
- Real-time Unix timestamp display
- Hobbies and dislikes sections
- Responsive design with gradient header

### 2. Contact Us (contact.html)
- Validated contact form with required fields
- Client-side form validation
- Error messaging for invalid inputs
- Success confirmation message
- Accessibility features (ARIA, labels)

### 3. About Me (about.html)
- Bio and personal introduction
- Program goals and aspirations
- Areas of low confidence
- Note to future self
- Extra thoughts and reflections

## Features

- **Fully Responsive**: Works seamlessly on mobile, tablet, and desktop
- **Accessible**: Semantic HTML, ARIA attributes, keyboard navigation
- **Modern Design**: Purple gradient theme with smooth animations
- **Form Validation**: Real-time validation with user-friendly error messages
- **Cross-page Navigation**: Easy navigation between all pages

## Technologies

- HTML5
- CSS3 (Flexbox, Grid, Custom Properties)
- Vanilla JavaScript
- No frameworks or libraries

## Validation Rules

**Contact Form:**
- All fields are required
- Email must be in valid format (name@example.com)
- Message must be at least 10 characters
- Success message displays only after valid submission

## File Structure

```
├── index.html          # Profile card page
├── style.css           # Profile card styles
├── script.js           # Unix timestamp functionality
├── contact.html        # Contact form page
├── contact.css         # Contact form styles
├── contact.js          # Form validation logic
├── about.html          # About me page
└── about.css           # About page styles
```

## Getting Started

1. Clone or download this repository
2. Open any HTML file in a modern web browser
3. Navigate between pages using the footer links

No build process or dependencies required!
